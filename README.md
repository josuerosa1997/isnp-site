# ISNP — site institucional

Site estático do Instituto de Saúde do Norte do Pará.

Domínio oficial: https://www.institutodesaudedonortedopara.com

## Publicação

GitHub Pages, branch `main`, diretório raiz (`/`). O arquivo `.nojekyll` mantém a publicação estática. O arquivo `CNAME` define o domínio oficial.

## Conteúdo

- `index.html`: página institucional e dados de contato.
- `styles.css`: identidade visual e layout responsivo.
- `app.js`: navegação e solicitação de proposta.
- `isnp-logo.png`: logo original fornecida pelo instituto.
- `cuidado-isnp.webp`: imagem ilustrativa.

O formulário prepara a mensagem no navegador. O visitante conclui o envio no WhatsApp ou no aplicativo de e-mail; não há coleta automática de dados por backend.

As informações sobre contratos e contatos foram fornecidas pelo instituto.
